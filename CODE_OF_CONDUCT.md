# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

By participating, you agree to uphold its terms. Please read the full text at the link above.

## Reporting

If you need to report a concern, open an issue on
[THU-SAGE/syll](https://github.com/THU-SAGE/syll/issues) or contact the current
maintainers directly if a public issue would be inappropriate.
