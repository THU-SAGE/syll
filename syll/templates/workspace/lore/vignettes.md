# Vignettes

This file is a placeholder for longer story scenes that may be added later. It is not currently loaded into the system prompt. Leave empty if you have nothing to add.

If you want to write vignettes, each one should be a short atmospheric scene — a single remembered moment in more detail than a `fragments.md` entry, but still under a page. They are for developers/writers to hold and evolve the worldview; the agent does not read them unless you explicitly wire them in.
